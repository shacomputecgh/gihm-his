## 🎬 Recording Tips

### Screen Recording
1. Open `http://localhost:5173/advert.html` in full screen (F11)
2. Use **OBS Studio** (free) to record
3. Set canvas to 1920x1080 for YouTube, 1080x1080 for Facebook
4. Record at 30fps, 5000kbps bitrate

### Voiceover
1. Use a clear headset microphone
2. Speak slowly and clearly
3. Add background music (royalty-free from YouTube Audio Library)
4. Music volume should be 20% of voice volume

### Editing
1. Use **CapCut** (free) for mobile editing
2. Add text overlays for key features
3. Use transitions between modules
4. Add your logo watermark in the corner

### Thumbnail
- Use a screenshot of the dashboard
- Add text: "300+ Hospital Modules"
- Use red/yellow/green (Ghana flag colors)
- Add ShaComputeC logo
